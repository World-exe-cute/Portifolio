Projeto principal

MyTube

  • React
  • Node.js
  • Express
  • MVC
  • reCAPTCHA v3

Este é o meu maior projeto, um clone do YouTube feito em React para o FrontEnd e Node.js com Express para o Backend, estruturado no padrão MVC (Model-View-Controller) e utilizando Recaptcha v3 do google. O site é responsivo, permite criar contas que guardam informações como inscrições, personalização, vídeos do usuário, histórico e vídeos curtidos.

Mais detalhes

Os vídeos que aparecem no feed são buscados através de relevância com as tags do usuário ou tags padrões, caso esteja deslogado. Os vídeos também têm informações guardadas no banco de dados como likes, visualizações, descrições e comentários que por sua vez também guardam informações.

As contas têm acesso à página de gerenciamento de canais quando estão logadas, onde podem verificar todos os vídeos e suas informações, análises gráficas do último vídeo, comentários de todos os vídeos, personalização de canal e informações.

Por fim, gostaria de pedir para que deixe um feedback, caso se sinta confortável e/ou encontre bugs no site. Mais informações na política de privacidade.

O site utiliza o Render gratuito, por isso o Backend demora cerca de 40 segundos para funcionar pela primeira vez.

Jogo · 2022

Ping-pong

  • HTML
  • CSS
  • JavaScript

Este é um jogo de ping-pong que criei por volta de 2022 feito em HTML, CSS e JavaScript, o jogo move a bolinha em linha reta frame por frame infinitamente, sempre verificando se ela está em contato com uma superfície, caso esteja ela inverte seu ângulo e continua a se mover.

Mais detalhes

O jogo detecta superfície nos retângulos e paredes, e a barra movida pelo jogador sempre segue o mouse e tem duas extremidades: direita e esquerda, fazendo o ângulo da bolinha ir preferencialmente para a direção dessa extremidade. O jogo acaba quando a bolinha cruza a linha vermelha ou quando todos os blocos somem, sendo honesto só consegui vencer o jogo uma vez.
