MyTube

Confira aqui

Este é o meu maior projeto, um clone do YouTube feito em React para o FrontEnd e Node.js com Express para o Backend, utilizando Recaptcha v3 do google. O site é responsivo, permite criar contas que guardam informações como inscrições, personalização, vídeos do usuário, histórico e vídeos curtidos. Os vídeos que aparecem no feed são buscados através de relevância com as tags do usuário ou tags padrões, caso esteja deslogado. Os vídeos também tem informações guardadas no banco de dados como likes, visualizações, descrições e comentários que por sua vez também guardam informações. As contas tem acesso a página de gerenciamento de canais quando estão logadas, onde podem verificar todos os vídeos e suas informações, análises gráficas do ultimo vídeo, comentários de todos os vídeos, personalização de canal e informações. O site utiliza o render gratuito, por isso o Backend demora cerca de 40 segundos para funcionar pela primeira vez.

Ping-pong

Confira aqui

Este é um jogo de ping-pong que criei por volta de 2022 feito em HTML, CSS e JavaScript, o jogo move a bolinha em linha reta frame por frame infinitamente, sempre verificando se ela está em contato com uma superfície, caso esteja ela inverte seu ângulo e continua a se mover. O jogo detecta superfície nos retângulos e paredes, e a barra movida pelo jogador sempre segue o mouse e tem duas extremidades: direita e esquerda, fazendo o ângulo da bolinha ir preferencialmente para a direção dessa extremidade. O jogo acaba quando a bolinha cruza a linha vermelha ou quando todos os blocos somem, sendo honesto so consegui vencer o jogo uma vez.
